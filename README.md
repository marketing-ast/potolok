# Bakha Potolok Landing

Static landing page for ИП Bakha Potolok.

## Files

- `index.html` - main landing page
- `contacts.html` - contact page
- `privacy.html` - privacy policy
- `personal-data.html` - personal data processing page
- `assets/css/styles.css` - shared styles
- `assets/js/main.js` - static request form placeholder
- `docs/reference/behance-landing-reference.md` - saved design reference notes

## Local check

```bash
npm run validate
```

No backend is used. The request form does not send data to a server.
